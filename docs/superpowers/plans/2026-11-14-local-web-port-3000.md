# Local Web Port 3000 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `http://localhost:3000` the consistent default frontend address for native and Docker development.

**Architecture:** Vite owns the native development port, while `WEB_PORT` owns Docker's host mapping. Backend CORS and email URL defaults must match the browser origin; internal container and API ports remain unchanged.

**Tech Stack:** Vite 8, Vitest 5, Docker Compose, ASP.NET Core/.NET 10, xUnit.

## Global Constraints

- Set native Vite development to port `3000` with `strictPort: true`.
- Set Docker's default `WEB_PORT` and every active development frontend URL to `3000`.
- Keep nginx container port `8080`, API port `5023`, and database ports unchanged.
- Keep `WEB_PORT` available as a Docker Compose override.
- Do not rewrite historical implementation plans that document old Sprint 0 defaults.

- [ ] **Step 1: Write the failing Vite configuration test**

Create `client/web/vite.config.test.ts`:

```ts
import type { ConfigEnv, UserConfigFn } from 'vite'
import { expect, it } from 'vitest'
import config from './vite.config'

it('uses the fixed local development port', async () => {
  const createConfig = config as UserConfigFn
  const env: ConfigEnv = {
    command: 'serve',
    mode: 'development',
    isSsrBuild: false,
    isPreview: false,
  }
  const resolved = await createConfig(env)

  expect(resolved.server).toMatchObject({ port: 3000, strictPort: true })
})
```
